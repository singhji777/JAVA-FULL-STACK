# API integration placeholder

This folder is reserved for connecting the React UI to your existing Spring Boot controllers later.
The current UI uses `AppContext.jsx` as in-memory demo state and does not make HTTP requests.

Suggested future files:
- `employeeService.js` — GET/POST/PUT/DELETE employee API calls
- `departmentService.js` — department API calls
- `authService.js` — login/logout API calls

No backend files or behavior have been changed.
